# CampusFest

Aplicación de escritorio en JavaFX para reservar y controlar entradas a los eventos de la universidad. Proyecto de semestre de Ingeniería de Software · Universidad de los Llanos.

## Estado

Base del proyecto: `pom.xml` (Java 21, JavaFX 21.0.5, H2 2.2.224, JUnit 5.10.2), las pruebas entregadas por los docentes en `src/test/java` y el contrato de las clases en `CONTRATO.md`.

## Requisitos

- JDK 21
- Maven 3.9 o superior

## Comandos

```bash
mvn compile
mvn test
```
